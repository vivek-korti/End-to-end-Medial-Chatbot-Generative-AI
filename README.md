## 🩺 Medical Chatbot System

An AI-powered chatbot designed to assist users with basic medical queries and symptom checks. This project leverages Natural Language Processing (NLP) to interpret user input and provide relevant health-related information in real-time.

### 🔍 Features

* Intelligent medical assistant for common symptoms
* Natural Language Processing using Python libraries
* Web interface built with Flask, HTML, and CSS
* User-friendly, responsive chat interface
* Basic first-aid and health advice generation

### 🛠️ Tech Stack

* **Languages**: Python, HTML, CSS
* **Frameworks**: Flask
* **Libraries**: NLTK / spaCy (as applicable)
* **Tools**: Jupyter Notebook (for prototyping), Git

### 📦 Installation

```bash
git clone https://github.com/vivek-korti/medical-chatbot-system.git
cd medical-chatbot-system
pip install -r requirements.txt
python app.py
```

### 🚀 How It Works

The chatbot takes user input through a simple web UI, processes the text using NLP, and responds with relevant health advice based on keyword matching and predefined logic.

* Created intuitive UI and integrated NLP for medical Q\&A
* Applied core AI concepts in a real-world healthcare scenario
